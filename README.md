# AI Email Generator

An AI-assisted email generation project organized into backend, frontend, and browser-extension components.

## Components

- **Backend:** API service for email-generation functionality.
- **Frontend:** User interface for interacting with the generator.
- **Browser extension:** Extension client for integrating the workflow into the browser.

## Repository layout

- `Email-Generator Backend/`
- `Email-Generator-Frontend/`
- `Email-Generator-Extension/`

## Getting started

1. Clone this repository.
2. Read the README and configuration instructions inside each component directory.
3. Install dependencies separately for the backend, frontend, and extension.
4. Configure local environment variables using placeholder values from the component documentation.
5. Start each component using its documented development command.

## Configuration and security

Do not commit API keys, access tokens, passwords, or production environment files. Use local environment variables or your deployment provider's secret manager. Check that each component's environment file contains only safe example values before publishing changes.

## Deployment

The repository includes a `render.yaml` deployment configuration. Review the service settings and provide required secrets through the deployment dashboard.
